# 🎮 Rock-Paper-Scissors

An interactive Rock-Paper-Scissors game built using HTML, CSS, and JavaScript, featuring random computer moves, score tracking, and Local Storage.

## 📸 Preview

![Rock Paper Scissors](./screenshot(215).png)

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Local Storage

## ✨ Features
- Play against the computer.
- Random computer moves.
- Automatic winner detection.
- Tracks wins, losses, and ties.
- Saves scores using Local Storage.
- Reset score option.

## 🚀 How to Run
1. Clone this repository.
2. Open `index.html` in your browser.
3. Start playing!
